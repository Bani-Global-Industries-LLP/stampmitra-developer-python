# Security Policy

Report suspected vulnerabilities privately to **security@stampmitra.in** (see <https://developer.stampmitra.in/.well-known/security.txt>). Please do not open public issues for security problems. Include the SDK version, Python version and reproduction steps; never include live API keys.

We aim to acknowledge reports within 3 business days. Only the latest 0.x release receives fixes.

Reminder: `sk_` API keys are server-side secrets. Do not embed them in client apps, commit them, or paste them into issues.
